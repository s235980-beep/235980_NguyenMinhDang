# He thong quan ly mon an

## 1. Gioi thieu
Du an xay dung he thong quan ly mon an tren nen tang dam may.

## 2. Cong nghe
- Frontend: React
- Backend: Node.js, Express
- Database: MongoDB Atlas
- Quan ly ma nguon: Git, GitHub
- Dong goi: Docker, Docker Hub
- Trien khai: Render

## 3. Cau truc du an
- frontend/: Ma nguon giao dien React
- backend/: Ma nguon backend API
- README.md: Tai lieu du an
- .gitignore: Cac tep Git bo qua

## 4. Huong dan cai dat
Cac huong dan cai dat frontend, backend va Docker se duoc cap nhat trong qua trinh thuc hien.

## 5. Cau hinh bao mat
Khong dua tep .env, mat khau, access token hoac chuoi ket noi co thong tin xac thuc len GitHub.
